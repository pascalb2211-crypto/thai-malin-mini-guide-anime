# Thaï Malin — vraie version test interactive

Cette version est faite pour tester le fonctionnement complet :
- 20 pages réellement distinctes ;
- flèches qui changent réellement l'image ;
- sommaire avec 20 miniatures ;
- favoris mémorisés ;
- bouton PDF via l'impression du navigateur ;
- plein écran ;
- liens externes ;
- navigation interne ;
- zones cliquables sur les visuels ;
- cases à cocher mémorisées avec localStorage.

Les 20 visuels proviennent de la planche de 20 pages déjà générée pour le mini-guide, avec la couverture autonome validée en page 1. La prochaine étape consiste à remplacer chaque visuel par sa version finale individuelle si nécessaire et à ajuster précisément les coordonnées des zones cliquables sur chaque page.
