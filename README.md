# Thaï Malin — HTML interactif sur image

Cette maquette démontre le principe validé :
- une image unique reste le visuel ;
- des zones transparentes HTML sont placées exactement au-dessus des éléments ;
- un clic sur une zone peut ouvrir une page interne, une fonction ou un lien externe ;
- les cases à cocher sont de vraies cases HTML et sont mémorisées sur l'appareil.

Le visuel `assets/page-01-reference.png` est une image de référence de la maquette. Pour la version finale, chaque page aura son propre visuel généré et ses propres coordonnées de zones cliquables.
